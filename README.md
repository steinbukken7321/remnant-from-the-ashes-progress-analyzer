# Remnant: From the Ashes — Analisador de Progressão

Site que lê o `profile.sav` e o `save_N.sav` de Remnant: From the Ashes e mostra
o que o seu mundo sorteou (Ward 13, Terra, Rhom, Corsus, Yaesha e Reisum) e o que
ainda falta coletar, com dicas de como encontrar, lutar e craftar cada item.

Tudo roda no navegador: os arquivos de save não são enviados para nenhum servidor.

## Como usar

1. Acesse: [https://steinbukken7321.github.io/remnant-mapa/](https://steinbukken7321.github.io/remnant-from-the-ashes-progress-analyzer/)
2. Abra a pasta `%LOCALAPPDATA%\Remnant\Saved\SaveGames` (Win+R).
3. Envie o `profile.sav` (inventário) e o `save_N.sav` (mundo). Também aceita `.bak`.
4. Escolha o personagem e o modo (Campanha ou Aventura) e clique nos eventos.

## Rodar localmente

Abra o `index.html` no navegador ou use a extensão Live Server do VS Code.

## Créditos

Baseado na lógica de leitura dos projetos hzla/Remnant-World-Analyzer,

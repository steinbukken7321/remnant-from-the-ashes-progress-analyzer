# Remnant: From the Ashes — Analisador de Progressão
Site estático; roda no navegador e os saves não saem do seu PC.
1. Abra `index.html` (Live Server no VS Code) ou publique no GitHub Pages (Settings → Pages → branch main / root).
2. Envie `profile.sav` e `save_N.sav` de `%LOCALAPPDATA%\Remnant\Saved\SaveGames` (aceita `.bak`).
3. Clique num evento para ver descrição, como lutar, escolhas que se excluem e o que craftar na McCabe.
`js/info.js` guarda os textos de cada evento: é só adicionar entradas com a chave do evento.
